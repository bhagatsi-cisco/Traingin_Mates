🎯 WHAT DOES THIS APP DO?
════════════════════════════════════════════════════════════════════════════

   ✨ Create Anonymous Chat Rooms
      • Click "Create New Chat Room"
      • Get a shareable 8-character code
      • Share with friends/colleagues

   👥 Real-Time Chatting
      • Everyone joins anonymously
      • Messages appear instantly
      • See who's typing
      • Join/leave notifications

   🔐 Privacy First
      • No sign-up required
      • No personal data collected
      • No server logging
      • Messages stored only during chat


💻 HOW TO USE IT
════════════════════════════════════════════════════════════════════════════

   Creating a Room:
   1. Click "Create New Chat Room"
   2. You get a room code (e.g., ABC12345)
   3. Click "Copy Room Code"
   4. Share the link or code with others

   Joining a Room:
   1. Enter the room code you received
   2. Click "Join"
   3. You'll get a random username
   4. Start chatting!

   Chatting:
   1. Type your message
   2. Press Enter or click Send
   3. Everyone in the room sees it instantly
   4. See who's online in the sidebar

❓ COMMON QUESTIONS
════════════════════════════════════════════════════════════════════════════

   Q: I see "Cannot find module" error
   A: Run `npm install` to install dependencies

   Q: Port 3000 is already in use
   A: Run `PORT=5000 npm start` to use a different port

   Q: How do I change the colors?
   A: Edit the colors array in server.js (around line 30)

   Q: Can I add features?
   A: Yes! The code is well-organized and easy to extend

   Q: Can I deploy this?
   A: Yes! Works on Heroku, AWS, Replit, and more

📞 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

   Problem: "Cannot connect to server"
   Solution: Check if npm start succeeded, verify port 3000

   Problem: "Room not found"
   Solution: Check room code spelling (case-insensitive), try creating new

   Problem: "Messages not updating"
   Solution: Refresh page, check browser console (F12), restart server

   For more help: Check README.md → Troubleshooting section
