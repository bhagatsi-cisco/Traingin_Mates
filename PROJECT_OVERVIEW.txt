🎯 HOW IT WORKS
─────────────────

HOME PAGE (index.html):
  ├─ User clicks "Create New Chat Room"
  │  └─ Backend generates unique 8-char room code
  │     └─ User redirected to chat.html?room=ABC12345
  │
  └─ User enters room code or clicks shared link
     └─ Joins existing room via chat.html?room=ABC12345


CHAT ROOM (chat.html):
  ├─ User joins room via WebSocket
  ├─ Assigned random anonymous username
  ├─ Loads message history
  ├─ Shows all online users
  │
  ├─ User can:
  │  ├─ Send messages (Enter or Send button)
  │  ├─ See others typing
  │  ├─ Copy room code/link
  │  └─ See real-time user join/leave
  │
  └─ User leaves → auto-cleanup after 1 hour


📡 API ENDPOINTS
──────────────────

CREATE ROOM:
  POST /api/rooms
  Response: { roomId: "ABC12345", shareLink: "/chat?room=ABC12345" }

GET ROOM INFO:
  GET /api/rooms/:roomId
  Response: { id: "ABC12345", userCount: 3, createdAt: "2024-11-17T..." }

SERVE PAGES:
  GET /           → index.html (home page)
  GET /chat       → chat.html (chat interface)


🔌 WEBSOCKET EVENTS
─────────────────────

CLIENT → SERVER:
  join-room(roomId, callback)
    → Callback: { success, messages[], userName, userCount, users[] }
  
  send-message({ roomId, message })
    → Server broadcasts to all users in room
  
  user-typing(roomId)
    → Notify others that user is typing


SERVER → CLIENT:
  user-joined({ userId, userName, userCount })
  
  receive-message({ id, userId, userName, message, timestamp, avatar })
  
  user-left({ userName, userCount })
  
  user-typing({ userName })

💾 DATA STORAGE
─────────────────

Currently: In-Memory Storage

What's stored:
  ├─ Active chat rooms (Map)
  ├─ Messages per room (Array)
  ├─ User info (name, ID, timestamp)
  └─ Cleaned up when room is empty

NOT stored:
  ✗ No database
  ✗ No persistent storage
  ✗ No user profiles
  ✗ No server logs of messages

🔧 TROUBLESHOOTING
────────────────────

PROBLEM: "Cannot find module"
SOLUTION: Run npm install

PROBLEM: Port already in use
SOLUTION: Use PORT=5000 npm start

PROBLEM: WebSocket connection failed
SOLUTION: Restart server, refresh browser, check firewall

PROBLEM: "Room not found"
SOLUTION: Check room code (case-insensitive), room may have expired

PROBLEM: Messages not showing
SOLUTION: Check browser console, verify Socket.IO loaded
